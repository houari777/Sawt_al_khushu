# صوت الخشوع — Sawt Al Khushu

تطبيق Flutter عربي بواجهة RTL للقراءة الهادئة، مع مكتبة نصوص محلية وإعدادات للصوت والسرعة والوقفات.

## الموجود في النسخة 0.3.0
- واجهة Material 3 عربية مع مظهر فاتح/داكن.
- محرر نص عربي، عداد كلمات، ومثال مشكول.
- حفظ النصوص محلياً على الجهاز.
- إعدادات سرعة القراءة ومستوى الصوت وحدّة الصوت والوقفة بين الفقرات.
- فحص توفر صوت عربي محلي على الهاتف.
- إيقاف القراءة وإعادة فحص محرك الصوت.

## حدود مهمة
هذه النسخة تستخدم محرك تحويل النص إلى كلام المثبت في Android. التحكم في الصوت والسرعة لا يعني أن المحرك يحقق التجويد أو مخارج الحروف وصفاتها. دعم الشدة والتشكيل يتأثر بمحرك الصوت نفسه، ويجب اختباره بأمثلة عربية مشكولة ومراجعة النتائج قبل اعتمادها. لا توجد بعد تسجيلات بشرية مدمجة ولا محرك Nabra/Sherpa مدمج في هذه النسخة.
