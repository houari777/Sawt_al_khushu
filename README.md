# صوت الخشوع — Sawt Al Khushu

تطبيق Flutter لكتابة النصوص العربية والاستعداد لقراءتها بصوت هادئ، مع دعم اتجاه RTL.

## الحالة الحالية

هذه نسخة تأسيسية. واجهة التطبيق لا تشغّل القراءة الصوتية بعد؛ يجب دمج محرك صوت محلي واختباره قبل تفعيل زر القراءة.

## الهدف

- العمل دون إنترنت بعد تثبيت التطبيق.
- دعم النص العربي والتشكيل.
- ضبط سرعة القراءة والوقفات.
- إضافة تسجيلات بشرية محلية ومحرك نطق اصطناعي محلي بعد التحقق من توافقهما.

## البناء

سيُضاف إعداد GitHub Actions لبناء APK بعد تجهيز ملفات Flutter وAndroid.
